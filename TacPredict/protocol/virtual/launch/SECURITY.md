# Security review findings — launch not cleared

This is an engineering/source review with local testing, **not an independent audit**. Severity refers to potential impact, not a claim of an exploited vulnerability. No user-fund custody is added by the virtual engine; native gas, application integrity, privacy and reward integrity still matter.

| Severity | Finding | State / mitigation |
|---|---|---|
| High | Quote cache lacked market identity | Fixed: market/deployment/wallet/order-scoped key and exact-intent check before wallet submission; regression tests. |
| High | Existing app dependency graph reports 18 high and 22 moderate advisories (40 total) | **Open launch blocker.** Audit includes wallet/provider schema/WebSocket dependency paths and Vite development tooling. Do not globally override Zod 3 to 4 or force a wagmi major upgrade without compatibility/deployed-wallet validation. Not silently waived. App manifests/lockfiles unchanged by this follow-up. |
| High | New runtime/actual provider sources and deployed wallet flow unverified | **Open.** On-chain proposer/arbiter authority is trusted, not cryptographic source truth. Metadata source policy and normalized evidence validation do not authenticate captured source payloads. An authorized malicious resolver can still propose false evidence. Separate operators, immutable rules, independent review, monitoring and actual provider fixtures required before enabling markets. |
| High | Production DB/geo/access/monitoring state not fully verified | **Open.** Source RLS tests do not prove current remote policy state; terms do not implement geofencing. Read-only DB schema inspection, staging rehearsal and production observability commissioning required. |
| Medium | Old canonical/stalled RPC data could be treated as fresh | Fixed/mitigated: projection age AND wall-clock head freshness checks; revision/nonce/minOut checks on-chain; pause/reconciliation remains operationally necessary. |
| Medium | Null expected cursor weakened DB CAS sequencing | Fixed: reject null/fractional cursor, timestamp and event inputs; stale lease, sequential parent, finality fences tested. SQL remains a draft, not applied in production. |
| Medium | Stored transaction intent could disagree with indexed event | Fixed: DB observation becomes invalid unless market/outcome/side/input/nonce match trusted canonical event. On-chain projection is not changed to fit an API claim. |
| Medium | Provider errors could expose credential-bearing URLs | Fixed/mitigated: enumerated public error boundary and fixed-code operational logs; no secret values printed/read from production bindings. Legacy application's broader error logging still needs its own audit. |
| Medium | Disappearing mined receipt regressed to pending | Fixed: retain previous block evidence and mark reorged; no hash/signature-only confirmation. |
| Medium | Gas expectations unclear | Fixed/mitigated: per-quote execution estimate plus explicit additional L1 fee/wallet full-fee review. No fixed-cost/zero-gas promise; reverted transactions can cost native ETH. |
| Medium | Continuous virtual indexer/alerts not commissioned | **Open deployment gate.** Dormant bounded CLI and health metrics implemented; existing legacy schedules are not repurposed or activated. |
| Medium | Pending UI state survives only while relevant instance/tab remains mounted | **Open UX/recovery validation.** Wallet/action nonce and receipt/projection checks prevent duplicate chain accounting; reload/replacement/dropped-transaction recovery still needs deployed-wallet E2E and durable pending-order UX before claiming complete readiness. |
| Low | Root lint formatting backlog | Open: existing full-repo lint fails. Changed virtual/disclosure sources pass scoped lint; no global suppression. |
| Informational / dev environment | Existing legacy protocol dev graph: 36 advisories (5 critical, 23 high, 6 moderate, 2 low) | Legacy test/compile dependency graph, not proof of production exploitability. Ganache/old dev tools remain isolated and unchanged to preserve old compilation/artifacts; review/replace in a separate compatibility effort. New isolated virtual toolchain audit: 0 advisories. |

The single new VirtualAMM Solidity source and its bytecode were not changed in this hardening pass; broader contract coverage includes deterministic randomized 2/3-outcome sequences, K/share/collateral/cash/basis conservation, actual reserve exhaustion, dust/extreme inputs, racing revisions, ownership/nonces, terminal winners/losers, disputes/void/pause and duplicate settlement. These tests are not exhaustive fuzzing, formal verification or independent economic review.

No new signing key or arbitrary balance editor. Seed budget is separate from grants; no redeemable asset call exists in the virtual path. Existing six Mainnet code hashes were read-only checked, not upgraded or activated. Local receipt evidence is explicitly local chain 31337. Sepolia and production are **not deployed or live**.
